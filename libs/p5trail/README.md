# Libraries for p5.js Code Trail

Used only inside the sketch preview of `p5_code_trail.html`. Other pages keep using `libs/p5.min.js` (p5.js 1.9.3).

| File | Version | License |
|------|---------|---------|
| `p5.min.js` | p5.js 1.11.4 | LGPL-2.1 |
| `p5.sound.min.js` | p5.sound 1.0.1 (ships with p5.js 1.11.4) | MIT |

p5.js 1.11.4 is the newest version p5play v3 supports.

Two add-ons are **not** stored here. The preview loads them from jsDelivr only when a sketch uses them:

- **p5.collide2D 0.7.3**: CC BY-NC-SA 4.0
- **p5play 3.35.5** (with planck.js): p5play's own license. Classroom use is covered by the separate "q5play Educational License" (https://q5play.org/teach). Confirm your course's license before assigning Level 15.
